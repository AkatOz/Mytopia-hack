The problem

Agents run on a developer's key or a shared service account. No one can list them, scope them, or stop one without stopping all.

“revoked tokens will still be valid if they are verified using any JWT library that verifies the signature and expiration of the token.”

Amazon Cognito developer guide, token revocation

“model behavior is not a security control.”

A10 Networks, AI agent security controls (Oct 2026), quoting Anthropic. A team must show what an agent can access, how it is authorized, how it is stopped.
So revocation lives in the gateway, on every call.

AWS, and what we learned

Cognitoone app client per agent; 5-min tokens from GetClientToken, no domain
DynamoDBone badge read per call is the kill switch, whole badge or one tool; append-only log
Lambdasix tools, invoked by the gateway's role; the agent has no key for it
BedrockNova 2 Lite through Strands; agent holds no AWS keys
IAM / STSnarrow role from session keys, 1-hour sessions, re-assumed before expiry

Learned: Cognito cannot revoke a machine token. An API Gateway authorizer never sees the tool name in the body. So the decision lives in our gateway.

Business, limits, next

Who and price

  • Platform and security teams letting agents use MCP tools. CISO buys, on-call uses.
  • Estimate: free to 100k decisions/month; about $99/month team tier; per-agent enterprise.
  • Estimate: AWS about $4 to $25 per million decisions, set by calls per token.

Honest limits

  • A call already past the check completes.
  • Admin token is a demo shortcut.
  • Client secret in a file stands in for attested workload identity.
  • Next: separate agent sandbox, Streams instead of polling, task-scoped badges, AgentCore path.

Built vs used

  • Built this weekend: gateway, launcher, agent, tools, infra, island scene. Claude Code wrote the engine and rebuilt the island.
  • Used: Ozi's earlier Mytopia renderer and recipes (island/ASSETS.md), three.js (MIT), two OFL fonts, AWS.

Prior art: Kong, LiteLLM, Cloudflare, AgentCore. We add the per-call badge read as the kill switch, and the island as the wall display.
